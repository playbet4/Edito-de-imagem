# Processador de Logo Imobiliário

React + Vite + TypeScript app for preparing property-brand logos: automatic background removal on the canvas, **interactive crop** on the image (drag frame and corners), preset export sizes, optional watermark, and PNG download — all **client-side** in the browser.

UI follows **Loft** brand cues (Inter, `#004D3D` green, `#FF6B4A` orange, glass-style panels).

## Setup

```bash
npm install
npm run dev
```

No API keys are required for the built-in editor.

## Scripts

| Command | Description |
| -------- | ----------- |
| `npm run dev` | Dev server |
| `npm run build` | Production build |
